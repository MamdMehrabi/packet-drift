# M01 — Foundation

## Objective

Initialize the project and establish reliable communication between the Wails frontend and Go backend.

## Deliverables

- Wails desktop application.
- React + TypeScript frontend.
- Go backend.
- Frontend-to-backend bridge.
- Initial project structure and development workflow.

## Tasks

1. Initialize the Wails project.
2. Set up the React + TypeScript frontend.
3. Establish the backend package structure.
4. Configure React Router.
5. Configure Zustand for frontend state management.
6. Expose a simple Go service to the frontend.
7. Verify development and production builds.

## Definition of Done

- `wails dev` runs successfully.
- The frontend can call exposed Go methods.
- Frontend state management is configured.
- The production application builds successfully.

Completed.
